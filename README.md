# Welcome to BHS👋

BHS, or Black Hole Simulator, is a program that can simulate black holes and other celestial bodies in the universe with actual physics.

BHS mainly uses C++ for the calculations. The GUI and rendering is done using GLFW and OpenGL.

## Dependencies

### GLFW
  - Windows: Go to https://www.glfw.org/download and select 64-bit Windows binaries
  - MacOS: Run ```brew install glfw``` on your terminal
  - Linux:
    - Debian:
      
      ```bash
      sudo apt install libglfw3-dev
      ```
      
    - Fedora:
      
      ```bash
      sudo dnf install glfw glfw-devel
      ```
      
    - Red Hat:
      
      ```bash
      sudo yum install glfw-devel
      ```
      
    - Arch X11:
      
      ```bash
      sudo pacman -S glfw-x11
      ```
      
    - Arch Wayland:
      
      ```bash
      sudo pacman -S glfw-wayland
      ```
      
### OpenGL (Note that it might come preinstalled with your device)
  - Windows: Install or update the latest official drivers of your graphic card
  - MacOS: It should be preinstalled 
  - Linux
    - Debian:
        
        ```bash
        sudo apt install libgl1-mesa-dev
        ```
        
    - Fedora:
        
        ```bash
        sudo dnf install mesa-libGL-devel
        ```
        
    - Red Hat:
        
        ```bash
        sudo dnf install mesa-libGL-devel
        ```
        
    - Arch:
        
        ```bash
        sudo pacman -S mesa
        ```
